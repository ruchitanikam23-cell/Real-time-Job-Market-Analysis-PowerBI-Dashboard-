Real-Time Job Market Analytics Dashboard

Project Overview

This project presents a Real-Time Job Market Analytics Dashboard created using Microsoft Power BI. It helps analyze job market trends through interactive visualizations and provides insights into job opportunities, salaries, skills, and experience requirements.

Features

* Job market overview
* Salary trend analysis
* Experience level analysis
* Top hiring locations
* Most in-demand skills
* Interactive dashboard visuals

Tools Used

* Microsoft Power BI
* Microsoft Excel (Dataset)

The repository includes a screenshot of the dashboard for reference.

Conclusion

This dashboard helps users understand current job market trends and supports data-driven career decisions.
